## 已完成的核心功能

### 任务执行引擎
- `TaskExecutor.execute()` / `execute_stream()` — 同步/流式双模式
- SSE 实时推送（`GET /tasks/{id}/events`）
- 自动记录 `model_name`、`elapsed_ms`、`ModelCallLog`
- 支持 `override_max_tokens` 任务级别覆盖
- 过期任务自动标记为 failed（`mark_stale_tasks`，30 分钟超时）
- 完成后自动保存 Markdown 到 `data/exports/` 分目录

### 主题系统
- 集中 Token 管理：`lib/theme-config.ts` 定义 20 个颜色 Token
- 暗/亮双主题，`useThemeConfig()` hook 统一调用
- TopBar 按钮切换，偏好存 localStorage
- 所有 10 个前端页面均使用 Token 适配

### 提示词模板系统
- 数据库存储模板，支持 `task_type` + `sub_type` 双层分类
- `is_default` 自动切换（同类型只有一个默认）
- 内容创作按 8 种文体联动筛选模板
- `TaskExecutor._pick_template` 优先查 DB 默认模板

### 导出模块
- `POST /export/tasks/{id}` — 生成 Markdown 文件到 `data/exports/`，记录到 `exports` 表
- `GET /export/{id}/download` — `FileResponse` 流式下载
- 任务详情页「导出」按钮一键下载 `.md` 文件
- 文件内容含任务 ID、类型、模型、耗时、输入、输出
