## 1. 系统概述

晨枢 AI 是一个**个人 AI 任务中枢**，提供统一入口完成以下任务：

- **简历面试** — 简历分析、岗位匹配、模拟面试、复盘报告
- **内容创作** — 8 种文体（论文、专利、小说、剧本、歌词、小红书、知乎、公众号）
- **信息搜集** — URL 抓取、去重摘要、汇总报告
- **arXiv 日报** — 研究方向追踪、论文拉取、中文简报
- **代码实验** — 代码生成、解释、调试（后续）

当前版本为 **MVP 阶段**，已完成工程骨架和模型配置模块。后续模块将逐步交付。

## 2. 系统架构

```
浏览器 (localhost:3000)
    ↓
Next.js 前端 (React 19 + Tailwind CSS 4)
    ↓
FastAPI 后端 (Python 3.14, port 8000)
    ↓
SQLite 数据库 + 本地文件存储
    ↓
外部：OpenAI 兼容模型 API
```

| 组件 | 技术 | 端口 |
|------|------|------|
| 前端 | Next.js 16 + React 19 | 3000 |
| 后端 API | FastAPI + Uvicorn | 8000 |
| 数据库 | SQLite | 本地文件 |
| 文件存储 | 本地目录 | `data/uploads/` |

## 5. 模型配置

### 5.1 添加模型

1. 打开工作台 → 点击左侧「模型设置」
2. 点击「添加模型」
3. 填写表单：

| 字段 | 说明 | 示例 |
|------|------|------|
| Provider | 服务商标识 | `openai_compatible` |
| Base URL | API 地址 | `https://api.openai.com/v1` |
| API Key | 密钥 | `sk-xxxxxxxx`（自动加密存储） |
| 模型名称 | 模型 ID | `gpt-4o` |
| 显示名称 | 页面展示名 | `默认写作模型` |

4. 点击「保存配置」
5. 在配置列表点击「测试」验证连接

### 5.2 支持的模型提供商

任何兼容 OpenAI API 格式的服务均可使用，包括但不限于：

- OpenAI (api.openai.com)
- 阿里云百炼 (dashscope.aliyuncs.com)
- 百度千帆 (qianfan.baidubce.com)
- 讯飞星火
- DeepSeek
- 智谱 GLM
- 本地部署模型 (Ollama 等，后续)

### 5.3 安全说明

- API Key 加密后存储在数据库中
- 页面展示时显示脱敏值（`sk-x****xxxx`）
- 日志中**不会**记录完整 API Key

## 8. 故障排查

### 8.1 前端页面打不开

```
检查项：
1. 确认 Node.js 已安装：node --version（应显示 v22.x）
2. 确认启动日志：cat logs/web/server.log
3. 确认端口未被占用：ss -tlnp | grep 3000
4. 尝试手动启动：cd apps/web && npm run dev
```

### 8.2 后端 API 无响应

```
检查项：
1. 确认 Python 虚拟环境存在：ls .venv/bin/python3
2. 确认启动日志：cat logs/api/server.log
3. 确认端口未被占用：ss -tlnp | grep 8000
4. 测试健康接口：curl --noproxy '*' http://127.0.0.1:8000/api/v1/health
```

### 8.3 模型连接测试失败

```
可能原因：
1. API Key 错误 — 重新在模型设置页填入正确的 Key
2. Base URL 错误 — 确认 API 地址包含 /v1 后缀
3. 网络不通 — 检查是否能访问该 API 服务（某些国内 API 可能需要代理）
4. 余额不足 — 检查 API 账户余额
```

### 8.4 启动脚本乱码

```
如果双击 .bat 文件出现 鈺愨晲 等乱码：
- 使用 WSL 终端运行：bash start.sh
- 或在 Windows Terminal（非 CMD）中运行 .bat
```

### 8.5 端口被占用

```bash
# 在 WSL 中查看占用端口的进程
ss -tlnp | grep -E "8000|3000"

# 强制释放
bash stop.sh
```

## 10. 安全注意事项

1. **API Key** — 不要将 `.env.local` 文件分享给他人
2. **简历和资料** — 上传的简历、研究资料会通过 API 发送给模型服务商，请注意隐私
3. **股票报告** — 系统生成的股票分析仅供参考，不构成投资建议
4. **论文/专利** — AI 生成的内容需要人工复核真实性和合规性
5. **网页抓取** — 遵守目标网站的 robots.txt 和使用条款
